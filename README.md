Yumi's Room - personal homepage skeleton

This project uses Vite + React + TypeScript. Run `npm install` then `npm run dev` to start a dev server.

Structure:
- index.html
- src/main.tsx
- src/App.tsx
- src/pages/Home.tsx
- src/components/Room.tsx
- public/assets/ (for images)
